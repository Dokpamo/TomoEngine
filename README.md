# TomoEngine

Jolt Physics의 알고리즘을 C++ 바인딩 없이 Rust로 이식하는 프로젝트입니다.

**현재 상태: 초기 이식 작업 중이며, 완성된 물리엔진이 아닙니다.**

## 목표

- 배포되는 라이브러리와 Cargo 빌드는 100% Rust로 구성합니다.
- Jolt C++ 링크, FFI 래퍼, C/C++ build dependency를 사용하지 않습니다.
- 원본 버전과 소스 위치를 기록하고 모듈별 동작을 테스트합니다.
- 수치적 정확성, 기능 범위, 성능, 결정론은 각각 검증하며 자동으로 보장한다고 주장하지 않습니다.

최초 구현은 별도 작업 브랜치에서 검토할 수 있도록 진행합니다.
